## Method note

Every label below was re-derived from the oracles before being compared with the Pass 1 label.
No Pass 1 reasoning was carried forward. All 48 rows (TC-01..TC-43 original, TC-44..TC-48
Pass 1 additions) were re-derived; the upheld rows cite their own re-opened evidence and name
the deciding check.

**Line citations verified in this pass** (Pass 1's were re-opened, not assumed):

- `srs.md` L177 = the FR-12 rule naming `POST/PUT/DELETE /api/products`; L178-179 = its two
  numbered requirements (valid JWT; `role = 'admin'` in token).

- `srs.md` L193 = `Admin có thể Thêm / Xem / Sửa / Xóa sản phẩm`; L194 = `Ràng buộc đầu vào`;
  L195 = `name` (`bắt buộc, tối đa 255 ký tự`); L196 = `price` (`bắt buộc, phải là số dương (> 0)`);
  L197 = `category_id` (`bắt buộc, phải chọn từ danh sách có sẵn`); L198 = the update-isolation
  invariant.
- `srs.md` L278-284 = SEC-01..SEC-07; L279 = SEC-02, L280 = SEC-03, L282 = SEC-05, L283 = SEC-06.
- `api_specification.md` L96-97 = `GET /api/products` + `?search=`; L101 = `GET /api/products/:id`;
  L103-107 = section 3.3 heading and the three verbs; L108-118 = the single shared
  `Body khi Thêm/Sửa` JSON block; L120-125 = section 3.4 categories; L135/L139 = cart endpoints;
  L169 = `GET /api/orders/:id`.

**Decisive negative finding, re-confirmed by opening section 3.3 in full:** `api_specification.md`
L103-118 documents no status code, no success response body, no error envelope, and no cascade
behavior for any of the three verbs. Every row asserting one of those without a hedge is
defective regardless of how plausible the assertion is.

No runtime execution was performed. This remains a design-time audit.

## Gap examined and deliberately not added

**Out-of-stock, or requested quantity exceeding stock, at checkout time.** No documented
product model contains a stock or inventory field — `api_specification.md` 3.3 (lines
103-118) and 6.3 (lines 216-234) list `name`, `price`, `description`, `imageUrl` and
`category_id` only — and neither `srs.md` nor the API specification mentions stock anywhere.
Writing such a case would require inventing a data dimension the specification does not
define, which is the same defect this pass charged against several prior rows. It is recorded
in `audit-log-v2.md` as a specification gap instead.

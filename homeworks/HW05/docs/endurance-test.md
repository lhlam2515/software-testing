# Endurance Test

This document prepares the 10-15 minute soak test required by HW05.

## Procedure

1. Choose the most stable Load-style parameter set.
2. Run the workflow for 10-15 minutes.
3. Monitor backend CPU and memory during the run.
4. Record the maximum stable throughput observed.
5. Record p95 and p99 from the real JTL or generated report.

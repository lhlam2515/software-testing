# JTL Analysis Prompt

Analyze ONLY the supplied raw JTL data.

Never invent missing values.

Distinguish:

- measured values
- calculated values
- inferred values
- proposed thresholds

Calculate:

- sample count
- error count
- error percentage
- average
- median
- p90
- p95
- p99
- min
- max
- throughput

If a metric is unavailable, state that it is unavailable instead of guessing.

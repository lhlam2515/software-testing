## Required Skills and Experience

### General requirements

- Bachelor's degree in Computer Science, Information Technology, or a related field.
- Experience in software testing (Junior (1+ year of experience) to Senior (4+ years of experience) level accepted).
- Strong English communication skills (verbal and written).
- Proven ability to work independently while also leading testing activities within the team.
- Strong problem-solving and analytical skills with a focus on quality.
- Good communication skills and ability to collaborate effectively with cross-functional teams.
- Open, proactive, and willing to continuously learn and adapt.
- Familiar with the Agile development methodologies.

### Technical Requirements

**_Hands-on experience in One or More areas_**

#### Manual Testing

- Experience in software testing for web-based applications.
- Solid testing experiences (test strategy, test approach, test plan, test techniques included black box, risk-based, exploratory, Non-UI testing, etc.)
- Strong understanding of software development life cycle (SDLC) and software testing life cycle (STLC).

#### Full-stack Testing

- Strong experiences in manual testing (requirement analysis, test strategy, test approach, test plan, test techniques including black box, risk-based, exploratory, Non-UI testing, etc.)
- Strong experience in testing for UI and API.
- Experience in coding with C#/ Java/JavaScript/ Python, or other programming languages.
- Experience in Automation testing using frameworks such as Selenium/Katalon/Playwright, etc.

#### Automation Testing

- Strong experience in Automation testing using frameworks such as Selenium/ Playwright/ Katalon/ Appium/ Cucumber/, etc.
- Proficient in coding with Java/JavaScript/etc.
- Experience in CI/CD (Apache Airflow, GitLab, GitHub Action, JenKins, etc.)

#### Performance Testing

- Strong experience with at least one mainstream performance testing tool such as JMeter, NeoLoad, LoadRunner, or equivalent.
- Experience in scripting and parameterization for web/API performance testing using REST, JSON, XML, RegEx, Groovy, JavaScript, Beanshell, or similar technologies.
- Familiarity with API and web service testing using tools such as Postman, SoapUI, or similar tools.
- Experience using monitoring/ observability tools such as Grafana, Splunk, AppDynamics, ELK, Dynatrace, or similar platforms.

### Nice to have

- Experience using AI chat tools (ChatGPT, Claude, Gemini, etc.) for research, debugging, and learning.
- Familiarity with at least one AI coding assistant (GitHub Copilot, Cursor, Claude Code, or similar).
- Ability to write clear, contextual prompts to generate code snippets, unit tests, or documentation.
- Awareness of AI output limitations and responsible AI use (data privacy, handling of sensitive client data).

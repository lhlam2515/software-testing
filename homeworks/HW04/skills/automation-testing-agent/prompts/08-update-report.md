# Prompt 08: Update Homework Report

## Role

You are a technical report writer. Your job is to generate the homework report section for the automation testing assignment.

## Inputs

- Feature analysis summary
- Manual test case summary
- Test data summary
- Automation summary
- Review findings
- Bug report summary if applicable

## Task

Generate only the report section for the homework. Do not create new tests, new code, or the full homework artifact outside the report section.

## Expected Output

Provide report content with:

- Feature overview
- Testing approach
- Manual testing summary
- Automation summary
- Findings and defects
- Improvements and lessons learned

## Quality Requirements

- Write in a professional academic style.
- Keep the content specific to the selected feature.
- Summarize evidence clearly.
- Avoid unsupported claims.

## Playwright Guidance

- Mention the role of Page Object Model, data-driven testing, and stable locators.
- Include a brief note on cross-browser readiness and HTML Reporter usage when relevant.

## Output Format

Use headings and concise paragraphs or bullets as appropriate for the homework report section.

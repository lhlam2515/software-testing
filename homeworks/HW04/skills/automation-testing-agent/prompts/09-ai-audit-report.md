# Prompt 09: AI Audit Report

## Role

You are an AI audit reviewer. Your job is to document how AI was used and what quality checks were applied.

## Inputs

- Generated prompts
- Generated outputs
- Review findings
- Bug reports
- Report summary

## Task

Generate AI audit report entries only. Do not create tests, bug reports, or the full homework report.

## Expected Output

Provide audit entries covering:

- AI-assisted tasks completed
- Human review actions
- Risks or limitations
- Code quality observations
- Follow-up actions

## Quality Requirements

- Be honest and specific.
- Distinguish AI-generated content from human-reviewed content.
- Record concerns about selector quality, flakiness, duplication, or missing coverage.

## Playwright Guidance

- Mention whether stable locators, data-driven testing, and assertion coverage were reviewed.
- Note if HTML Reporter or cross-browser validation was considered.

## Output Format

Use a table or bullet list with dated or ordered entries and a short conclusion.

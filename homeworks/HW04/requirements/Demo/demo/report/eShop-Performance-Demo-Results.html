Run the whole demo yourself

bash demo/run-demo.sh          # runs all 3 tests, writes demo/out/

# or one at a time:
node mock/server.js &

k6 run demo/spike.js          # jumps, then recovers
Numbers here are from the mock eShop (hard limit 300 concurrent). A real eShop will break at different numbers — point the suite at it with -e BASE_URL=http://localhost:<port> and re-run.

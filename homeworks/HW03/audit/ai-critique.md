# AI Critique

I used AI as a helpful starting point in this assignment, but I learned that its output still needed careful checking. It was useful for organizing the workflow, explaining the compatibility-testing process, and giving me a structure for the audit and report documents. However, some of the AI’s suggestions were too generic and did not fully reflect the actual EMS screens or the evidence I had available. In particular, it could describe what a good Task 3 workflow should look like, but it could not verify the real browser behavior, screenshot details, or the exact completeness of my project files. It also could not catch the fact that I was unable to recruit five participants for user testing, so that limitation had to be identified and documented by me instead of being filled in by AI. The issue was not that the AI was useless, but that it was working from patterns rather than the real state of my assignment. The main principle I learned is that AI should be treated as an assistant for drafting and planning, not as a source of truth. I should use it to save time and clarify ideas, but I still need to verify every important claim against the actual files, screenshots, and testing results before submitting anything.
